All-role evaluation timeline

Look backward to train, then forward to test.

The frozen test is not used to choose model settings. After evaluation is recorded, the local portal artifact is refitted on the complete saved training cohort—including reduced-weight low-opportunity rows—so it can use the latest research snapshot.

  1. 1Define targets

    Build same-role, same-season percentiles with opportunity adjustment and low-sample shrinkage.

  2. 2Train before 2025

    Fit regularized line models using the training-cohort rule saved with the model artifact.

  3. 3Choose inside training

    Select regularization strength without using the frozen season.

  4. 4Test on 2025

    Record error, rank agreement and performance against a simple declared baseline.

  5. 5Check stability and calibration

    Use earlier rolling origins, a separate athlete-disjoint group-fold diagnostic, top-decile checks and athlete-clustered bootstrap intervals where samples allow.

  6. 6Refit for the portal

    Use the full saved training cohort only after the evaluation result has been frozen and labeled.

How to read the table

Evidence labels answer narrower questions than confidence.

MAE

Average distance between predicted and observed percentiles. A model must be compared with its declared baseline, not judged from MAE alone.

Rank agreement

How well the predicted ordering follows the observed ordering. It does not show perfect calibration or causal explanation.

Evidence gate

A saved rule combining baseline improvement, sample support and resampling evidence. “Supported” is still research support, not deployment approval.

Additional diagnostics: each fitted head can now report athlete-disjoint error, fixed-bin percentile calibration, top-decile recognition and a rolling-origin prediction range. These make failure modes more visible; they do not turn a cross-sport analogy into a validated transfer forecast.
