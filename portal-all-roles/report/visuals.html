Read the bars as evidence, not grades.

A longer data bar means more records or better coverage. In the error chart, the opposite is true: shorter is better.

All values come from the repository’s frozen five-season reports.

Dataset depth

The NFL supplies more than half the rows.

A player-season is one athlete in one season. Larger panels give the project more examples, but size does not guarantee that every role or measurement is equally well represented.

Physical data coverage

Soccer build data is the clear bottleneck.

This chart requires both listed height and listed weight. It measures whether values are present—not whether they were measured in that season or under a common testing protocol.

From roster row to model label

Not every recorded season should train a model.

“Scored” rows have enough information for a descriptive result. “Eligible” rows also clear the stricter opportunity threshold needed for supervised training.

Model evidence

A fitted model is only the first checkpoint.

Each family starts with 26 registered target roles. “Passed” means it cleared that family’s internal evidence gate; it does not make a cross-sport claim deployment-ready.

2025 holdout check

Recent playing history beats a neutral guess.

Average error is measured in points on the 0–100 percentile scale. Shorter bars are better. These are selected same-sport examples, not proof that ability transfers between sports.

Cross-sport bridge

The transfer layer is an analogy, not a success forecast.

The bridge asks whether shared performance themes can reconstruct a target role’s patterns. It has no large ground-truth sample of athletes who actually switched between these sports.
