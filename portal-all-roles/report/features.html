The translation path

The raw number is never compared across sports.

A basketball steal and a hockey takeaway remain different events. Comparability is introduced only after each statistic has been adjusted and ranked inside its own role-season setting.

  1. Record the eventUse the sport’s own points, assists, tackles, pressures, saves or other public statistics.
  2. Account for opportunityTurn counts into role-appropriate rates, such as per 36 minutes, per 60 minutes or per target.
  3. Reduce small-sample extremesPull short appearances toward the eligible role-season average according to how much opportunity the player had.
  4. Rank comparable peersConvert the adjusted value into a percentile among athletes in the same sport, role and season.
  5. Build a role domainCombine related percentiles with declared, reviewable weights.
  6. Map a shared themeUse only named themes shared by both source and target roles in a cross-sport analogy.

Reliability shrinkage

The adjusted rate blends the player’s observed rate with an opportunity-weighted role-season average. More opportunity gives the player’s own rate more influence.

reliability = opportunity ÷ (opportunity + prior exposure)
